# meuTreino API REST

---

### Tecnologias utilizadas:

* Persistência de dados: PostgreSQL
* Back-End: Java com Spring Framework

### Objetivos do projeto:
    O principal objetivo do projeto foi manter um histórico de treinos
    realizados na academia. Com essa implementação, agora eu posso
    ter um controle maior sobre como os treinos se desenvolvem, porque
    eu tenho acesso a treinos passados, assim como detalhes que vão de
    exercícios até séries de cada um desses treinos passados.

### Por que uma API REST ?
    A API REST faz com que seja possível concluir um objetivo do futuro,
    que é criar uma versão mobile do aplicativo, para ter mais pratici-
    dade ainda na hora do treino. Além disso, a crescente tendência ao
    desenvolvimento de APIs REST para escalabilidade de sistemas certa-
    mente foi um fator decisivo que me fez ter interesse em aprofundar no
    assunto.

### Estado do projeto
    O back-end está totalmente funcional, enquanto o front-end ainda não
    foi desenvolvido. Inicialmente, o front-end será implementado com 
    tecnologias da WEB (Javascript, HTML, CSS), com o objetivo de expandir
    o funcionamento para um aplicativo mobile no futuro.
